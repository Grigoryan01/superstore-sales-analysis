# Superstore Sales Analysis

End-to-end analysis of US retail sales data using Python, SQL and Power BI.

## Project Overview

This project analyses sales data from a US retail superstore that sells furniture, office supplies and technology products to consumers, corporate clients and home offices. It covers data cleaning, exploratory data analysis, SQL analysis, an interactive dashboard, and business insights and recommendations.

## Dataset

| Item | Detail |
| --- | --- |
| Source file | `train.csv` |
| Size | 9,800 rows, 18 columns |
| Period | January 2015 to December 2018 |
| Orders / customers | 4,922 orders, 793 customers |
| Geography | United States (4 regions, 49 states) |
| Total sales | $2,261,536.78 |

Each row is one product line in an order. The data has no profit, discount or quantity columns, so the analysis measures revenue, not profit.

**Main columns:** Order ID, Order Date, Ship Date, Ship Mode, Customer ID, Segment, City, State, Region, Product ID, Category, Sub-Category, Product Name, Sales.

## Tools Used

- **SQL** (SQLite) for business analysis
- **Power BI** for the dashboard
- **Git and GitHub** for version control

## Key Findings

- Sales grew 30.6% in 2017 and 20.3% in 2018, after a 4.3% dip in 2016.
- September to December bring in 51.8% of yearly sales, and November is the strongest month.
- Technology earns the most (36.6% of sales) from the fewest order lines.
- California and New York together make up 33.2% of all sales.
- The top 20% of customers generate 48.5% of sales.
